Display beautiful restaurant and cafe menus for food and drinks.

== Description ==

MenuCraft helps restaurants and cafes present their food and drink menus on any WordPress site. Features will be added incrementally.

== Installation ==

1. Upload the `menucraft` folder to the `/wp-content/plugins/` directory.
2. Activate the plugin through the "Plugins" screen in WordPress.
